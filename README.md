❄️ IceStream – Operations Intelligence Dashboard
📌 Project Overview

IceStream is an end-to-end Operations Intelligence and Predictive Maintenance platform built to monitor asset health, detect abnormal sensor behavior, calculate operational risk, and support data-driven maintenance decisions.

The project combines Data Engineering, Data Analytics, Machine Learning, PostgreSQL, and Streamlit into a single interactive dashboard.

🎯 Objectives
Monitor asset and sensor performance
Analyze operational sensor data
Detect abnormal machine behavior
Identify high-risk assets
Calculate asset-level risk scores
Prioritize maintenance activities
Generate analytical reports
Monitor data and pipeline health
Provide management-level operational insights
